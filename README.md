# qr-pinzas-la-guinda

Páginas de redirección para los QR de las pinzas 27,5x40 cm "La Guinda" (Q3 Infantil).
Cada QR apunta a `/pagNN/` (la hoja del PDF), que redirige a https://www.falabella.com/falabella-cl.

| Hoja | Marca | Prenda |
|------|-------|--------|
| pag02 | Coniglio | Camisa |
| pag03 | Coniglio | Traje de baño |
| pag04 | Coniglio | Enterito |
| pag05 | Ecko Unltd | Pack polera + calcetín |
| pag06 | Ecko Unltd | Traje de baño |
| pag07 | Ecko Unltd | Polera |
| pag08 | Ecko Unltd | Polera y short |
| pag09 | Federation | Polera |
| pag10 | Federation | Traje de baño |

La hoja 1 del PDF es la portada y no lleva QR.

Para cambiar el destino de un QR, reemplaza la URL en `pagNN/index.html` (aparece cuatro veces).
